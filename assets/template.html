The disk choice matters more than the processor choice Premium SSD costs $72.59 more each month than Standard SSD, or $871.08 each year. For that, Premium delivers fifteen times the IOPS (7,500 against 500) and four times the throughput, and it carries no transaction charges. The Standard SSD figure is a floor, because transactions bill separately. If the workload is I/O sensitive, choose Premium and treat the difference as immaterial.

Assumptions

  • 730 hours per month, running continuously.
  • Pay-as-you-go rates. No reserved instances, savings plans or Azure Hybrid Benefit applied. A one-year reservation would reduce the compute line further.
  • Your price applies {{DISCOUNT_PCT}} percent to every Azure consumption meter.
  • The Red Hat license is charged at the 8 vCPU tier in all three options.
  • Locally redundant disks. Zone-redundant costs approximately 50 percent more.
  • No size includes a local temp disk. Add $63.77 per month for AMD E8ads_v6 if local scratch space is required.
  • Excluded: outbound data transfer, backup, snapshots, support plans, Standard SSD transaction charges, monitoring and log ingestion, public IP addresses and load balancers.

Next steps

  1. Confirm whether the workload is I/O sensitive. This decides Premium or Standard SSD and is worth $871 per year.
  2. Confirm no application or license constraint requires an Intel processor.
  3. Confirm whether any software on the VM is licensed per core. If so, Option 3 may be worth the reduced core count.
  4. Confirm whether local scratch space is needed on the VM.
  5. Tell us if the VM will run continuously. If so, a reservation reduces the compute cost further and we can re-price.
